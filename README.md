## 评分与候选

- 总分先四舍五入为整数再分档：0–49当前任务不适配；50–64适配证据偏弱；65–79有条件适配；80–100适配支持较强。距分界不超过2分标记临界。
- 加权任务方向分至少60，分散任务差异分至少50；总分再高也不能抵消职责门槛。26/52周跨档或门槛结论变化时提示先观察。
- 相关性是−1至1的系数：|r|<0.30弱，0.30至不足0.60中等，0.60至不足0.80强，0.80起极强；负号表示反向。
- 分档属于明确的人为研究规则，未做样本外校准；不是买入信号或收益概率。规则版本见`research/score_guidance.json`。
- 角色研究分：方法证据25%、角色适配35%、近期行为20%、组合必要性20%。本期12只与历史9只分别标注日期；历史模块另提供三种权重敏感性。
- 这是研究者按证据评档，不是经理能力排行、预测概率或投资收益模型。不同职责不可按总分互换。
- 遍历27,811条名录的名称和类型字段，6,214条满足入口规则；从中目的性选取8只外部候选，6只采集8,328条C类净值。
- 名录过滤不等于全市场逐只尽调。替换实验只覆盖已列76.6%研究子组合，不包括现金和未识别部分。
- 低相关候选仍有收益、回撤及费用代价，暂无已证实全面更优、可以直接执行的新增或替换结论。
